## 喜蜘蛛是什么？

**喜蜘蛛**是一张开放的全球资金网络地图。

它尝试把分散在不同国家、地区和金融体系中的：

- 法定货币
- 银行
- 支付平台
- 金融服务
- 加密货币交易所
- 稳定币
- 加密资产
- 区块链
- 数字钱包
- 卡产品
- Visa / Mastercard
- 商户
